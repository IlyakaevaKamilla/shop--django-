# 🛍️ Интернет-магазин товаров для дома

Современный интернет-магазин на Django с полным функционалом: каталог, корзина, избранное, оформление заказов и удобная админ-панель.

![Django](https://img.shields.io/badge/Django-092E20?logo=django&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)
![Bootstrap](https://img.shields.io/badge/Bootstrap5-7952B3?logo=bootstrap&logoColor=white)

## ✨ Возможности

### 👤 Пользовательская часть

| Модуль | Описание |
|--------|----------|
| 🔐 **Аутентификация** | Регистрация, вход/выход, защита личного кабинета |
| 📂 **Каталог** | Просмотр товаров по категориям с пагинацией |
| 🔍 **Поиск** | Поиск по названию товара |
| ❤️ **Избранное** | Добавление/удаление, статус отображается везде |
| 🛒 **Корзина** | Изменение количества, выборочная покупка, автопересчёт суммы |
| 📝 **Оформление** | Автозаполнение из профиля, сводка заказа |
| 📧 **Email** | Подтверждение заказа покупателю и уведомление админу |

### 👨‍💼 Административная панель

| Модуль | Описание |
|--------|----------|
| 📦 **Товары** | CRUD, акционные цены, остатки на складе |
| 🖼️ **Галерея** | Несколько изображений на товар |
| 📋 **Категории** | Управление категориями с картинками |
| 📊 **Заказы** | Просмотр и изменение статуса |
| 📈 **Аналитика** | Счётчики в избранном и корзине |

### 📧 Email-уведомления

| Кому | По какому принципу |
|--------|----------|
| 👨‍💼 Письмо администратору | Приходит на email, указанный в is_staff=True |
| 👤 Письмо покупателю | Приходит на email, указанный при оформлении |

## 🛠 Технологии

Backend
- **Django 5.1** — основной фреймворк
- **SQLite** — база данных
- **Django Auth** — система аутентификации
- **SMTP (Mail.ru)** — отправка писем
- **Class-based views** — организация логики
- **Mixins** — переиспользование кода

Frontend
- **Bootstrap 5** — адаптивная вёрстка
- **FontAwesome 6** — иконки
- **Django Template Engine** — шаблонизация
- **CSS3** — кастомные стили
- **Адаптивный дизайн** — для всех устройств

## 🚀 Быстрый старт

клонировать репозиторий и перейти в рабочую папку
```
git clone git@github.com:IlyakaevaKamilla/shop--django-.git
cd shop
```
создать виртуальное окружение
```
python -m venv venv 
```
активировать вирутальное оеружение
```
. venv/scripts/activate (Windows)
source venv/bin/activate (Linux/MacOS)
```
установить зависимости
```
pip install -r requiremets.txt
```
применить миграции
```
python manage.py migrate
```
создать суперпользователя
```
python manage.py createsuperuser
```
запустить сервер разработки
```
python manage.py runserver
```
### 🔍 Открой http://127.0.0.1:8000
